A compact, deterministic Python 3.13 chess engine built for the [make.fun Tiny Chess bounty](https://make.fun/bounty/tiny-chess-01).

## Run

Run `main.py` inside the Tiny Chess environment with Python 3.13. The harness supplies `MAKEFUN_ENV_URL`.

```sh
python3.13 main.py
```
